# ISSUE-001: 信令限流掐死中继传输并伤 P2P 协商，缺块静默交付损坏文件

- **状态**: done
- **优先级**: P0
- **区域**: src/room.ts, public/js/webrtc.js

## 问题

isRateLimited 10msg/s 一刀切：中继 chunk 200/s 实发 10/s 被静默丢弃，重传耗尽报"数据块重传次数过多"；ICE candidate 密集发送同样被丢。file-end 缺块仍拼 Blob 交付损坏文件。

## 修复方案

按类型分池：relay-data/ice-candidate 用字节速率令牌桶(2MB/s)，控制面保留低配额，超限回错误帧；缺块 NACK 重传，仍缺则中止传输并提示失败，绝不交付损坏文件。
