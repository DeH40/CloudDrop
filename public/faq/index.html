Frequently Asked Questions

Is there a file size limit?

No. Since CloudDrop transfers files directly between devices (P2P), there is no arbitrary file size limit imposed by us. The only limit is your browser's capability and your device's available storage.

Are my files stored on a server?

No. CloudDrop uses WebRTC for peer-to-peer transfer. Files are streamed directly from the sender to the receiver. We never store your files.

Is it secure?

Yes. All transfers are encrypted using DTLS (Datagram Transport Layer Security) via WebRTC. Additionally, we use end-to-end encryption for file content to ensure privacy.

Why can't I connect to another device?

Ensure both devices are on the same network or have internet access. If you are on a restrictive network (like a corporate firewall), connection might fail. Try refreshing the room code.
